# คู่มือการติดตั้ง Security 51 Thai Mod (เวอร์ชัน 0.1.3-beta)

คู่มือนี้แนะนำขั้นตอนการติดตั้ง การอัปเดต และการถอนการติดตั้งม็อดภาษาไทยสำหรับเกม **Security 51** (Steam Build `25104142`)

---

## 1. สิ่งที่ต้องเตรียมก่อนติดตั้ง (Prerequisites)

1. **ตัวเกม Security 51 ลิขสิทธิ์แท้บน Steam** (Build ID: `25104142`)
2. **BepInEx Unity IL2CPP x64** (แนะนำรุ่น `6.0.0-be.785+6abdba4`)
   - นำไฟล์ BepInEx ไปวางในโฟลเดอร์เกม
   - **เปิดเกม Security 51 ขึ้นมา 1 ครั้งจนถึงหน้าเมนูหลัก แล้วปิดเกม** (ขั้นตอนนี้จำเป็นมาก เพื่อให้ BepInEx สร้างไฟล์ระบบ `interop` ให้พร้อมใช้งาน)
3. **ปิดตัวเกม Security 51 ทุกครั้งก่อนทำการติดตั้งหรือถอนการติดตั้ง**

---

## 2. วิธีการติดตั้ง (เลือกวิธีใดวิธีหนึ่ง)

### วิธีที่ 1: ติดตั้งแบบคลิกเดียว (Single-Click Install — แนะนำสำหรับผู้ใช้ทั่วไป)

1. **แตกไฟล์ (Extract)** ไฟล์ ZIP ของม็อดภาษาไทยออกมาไว้ในโฟลเดอร์ใดก็ได้ (ห้ามรันไฟล์จากข้างใน ZIP โดยตรง)
2. ดับเบิลคลิกไฟล์ **`Install-SingleClick.cmd`**
3. ระบบจะทำงานโดยอัตโนมัติ:
   - ค้นหาตำแหน่งที่ติดตั้งเกม Security 51 จาก Steam ให้อัตโนมัติ
   - ตรวจสอบความถูกต้องของตัวเกมและไฟล์ BepInEx
   - หากเคยลงม็อดรุ่นเก่าไว้ ระบบจะทำการอัปเดตเป็นรุ่นล่าสุดให้อัตโนมัติ
4. เมื่อหน้าต่างแสดงข้อความสำเร็จ สามารถเข้าเล่นเกมได้ทันที!

---

### วิธีที่ 2: ติดตั้งผ่าน PowerShell (กรณีติดตั้งเกมในตำแหน่งพิเศษ)

หากตัวติดตั้งแบบคลิกเดียวหาตัวเกมไม่พบ หรือคุณย้ายเกมไปไว้โฟลเดอร์เฉพาะ:

1. เปิด **PowerShell** ในโฟลเดอร์ที่แตกไฟล์ม็อดไว้
2. รันคำสั่งต่อไปนี้ (เปลี่ยน Path ตัวเกมให้ตรงกับเครื่องของคุณ):

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Install-ThaiMod.ps1 -GamePath "D:\SteamLibrary\steamapps\common\Security 51"
```

3. เมื่อระบบแสดงข้อความ `Security 51 Thai Mod 0.1.3 installed.` แสดงว่าติดตั้งเสร็จสมบูรณ์

---

## 3. วิธีตรวจสอบว่าม็อดทำงานเรียบร้อย

1. เปิดเกม Security 51 ตามปกติผ่าน Steam
2. สังเกตหน้าเมนูหลัก ข้อความและเมนูการตั้งค่าต่าง ๆ จะแสดงผลเป็นภาษาไทย
3. เมื่อเข้าเกมและคุยกับ NPC ด้วยปุ่ม `[SHIFT]` ข้อความบทสนทนาจะแสดงเป็นภาษาไทยอย่างถูกต้องและลื่นไหล ไม่มีอาการกระตุกหรือเฟรมดรอป
4. หากต้องการตรวจสอบ Log ให้เปิดดูไฟล์:
   `Security 51\BepInEx\LogOutput.log`
   จะพบบรรทัด:
   ```text
   [Info :Security 51 Thai Mod] Security 51 Thai Mod 0.1.3 loaded with 3481 translations.
   [Info :Security 51 Thai Mod] Created Thai TMP fallback from bundled font 'NotoSansThai-Variable.ttf'.
   [Info :Security 51 Thai Mod] Applied 3481 Thai term values (UpdateSources).
   ```

---

## 4. วิธีถอนการติดตั้ง (Uninstall)

หากต้องการลบม็อดภาษาไทยออกเพื่อกลับไปใช้ภาษาอังกฤษดั้งเดิม:

1. ปิดตัวเกมให้เรียบร้อย
2. เปิด PowerShell ในโฟลเดอร์ม็อด แล้วรันคำสั่ง:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Uninstall-ThaiMod.ps1 -GamePath "D:\SteamLibrary\steamapps\common\Security 51"
```

3. ระบบจะทำการลบเฉพาะไฟล์ของม็อดภาษาไทยออก และกู้คืนไฟล์เดิมจากข้อมูลสำรอง โดยไม่ส่งผลกระทบต่อไฟล์ BepInEx หรือม็อดตัวอื่น ๆ

---

## 5. การแก้ไขปัญหาที่พบบ่อย (Troubleshooting & FAQ)

- **Q: ดับเบิลคลิก `Install-SingleClick.cmd` แล้วหน้าต่างปิดตัวเองทันที?**
  - **A:** ให้คลิกขวาที่พื้นที่ว่างในโฟลเดอร์ม็อด > เลือก *Open in Terminal* หรือเปิด *PowerShell* แล้วพิมพ์ `.\Install-SingleClick.cmd` เพื่อดูข้อความแจ้งเตือน เช่น เกมยังเปิดค้างอยู่ หรือยังไม่ได้ลง BepInEx
- **Q: เข้าเกมแล้วยังเป็นภาษาอังกฤษเหมือนเดิม?**
  - **A:** ตรวจสอบว่าติดตั้ง BepInEx ถูกรุ่น (ต้องเป็น Unity IL2CPP x64) และได้เปิดเกมทิ้งไว้ 1 ครั้งก่อนลงม็อดหรือไม่
- **Q: ตัวหนังสือภาษาไทยขึ้นเป็นกล่องสี่เหลี่ยม (Missing Glyphs / Square Boxes)?**
  - **A:** ตรวจสอบว่าในโฟลเดอร์เกม `Security 51\BepInEx\plugins\Security51Thai\fonts\` มีไฟล์ `NotoSansThai-Variable.ttf` ครบถ้วนหรือไม่
